# tools

A personal collection of small, self-contained tools, scripts, and support assets I reach for often enough to want them in one place. Most entries live in their own directory and are intended to be usable independently.

## Contents

- **[converter-json-protobuf](./converter-json-protobuf)** — Convert protobuf payloads between binary wire format and JSON for inspection, editing, and replay.
- **[cypress-docker](./cypress-docker)** — Dockerfiles and `docker-compose` helpers for running Cypress inside containers against the local machine.
- **[configs](./configs)** — Personal terminal and shell configuration snippets for Alacritty, tmux, and zsh.
- **[fonts](./fonts)** — Archived Meslo Nerd Fonts files used by the terminal and prompt configuration in this repo.
- **[nx-console-ioc-check](./nx-console-ioc-check)** — Read-only macOS scanner for indicators of compromise from the malicious Nx Console `18.95.0` supply-chain incident.
- **[shell](./shell)** — Small shell utilities and terminal helpers.

See each subdirectory for usage details where available.
