# tools

A personal collection of small, self-contained tools and scripts I reach for often enough to want them in one place. Each tool lives in its own directory with its own README explaining what it does and how to use it.

## Contents

- **[converter-json-protobuf](./converter-json-protobuf)** — Convert protobuf payloads between binary wire format and JSON for inspection, editing, and replay.
- **[nx-console-ioc-check](./nx-console-ioc-check)** — Read-only macOS scanner for indicators of compromise from the malicious Nx Console `18.95.0` supply-chain incident.

See each subdirectory's README for usage details.
